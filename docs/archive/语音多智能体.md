# 项目文档：基于知识图谱的高血压健康教育智能体

## 1. 项目概述

本项目在 Pipecat 多智能体框架中实现 **健康教育咨询智能体 (Education Agent)**，采用 **Neo4j 图数据库**构建高血压领域知识图谱，替代传统的 RAG 检索方案。

**为何选择知识图谱？**

- **关系推理能力**：能回答“哪些降压药不适合与高钾食物同服？”这类多跳关系问题
- **结构化知识**：将疾病、症状、药品、食物、运动等实体及其关系显式建模
- **精确性**：避免 RAG 的语义检索偏差，尤其适合医疗场景

**参考项目**：基于知识图谱的心血管疾病问答系统、高血压健康干预知识图谱、高血压知识图谱构建与应用研究等。

## 2. 技术栈

| 组件 | 技术选型 | 说明 |
|------|---------|------|
| 框架 | Pipecat + Pipecat Flows | 语音管线编排 + 结构化对话 |

## 3. 知识图谱设计

### 3.1 实体类型（7类）

参考医疗知识图谱的实体设计：

| 实体类型 | 示例 |
|---------|------|
| 疾病 (Disease) | 高血压、原发性高血压 |
| 症状 (Symptom) | 头晕、头痛、心悸 |
| 药品 (Drug) | 硝苯地平、厄贝沙坦 |
| 食物 (Food) | 香蕉、咸菜、芹菜 |
| 运动 (Exercise) | 快走、游泳 |
| 检查 (Exam) | 血压测量、心电图 |
| 科室 (Department) | 心内科 |

### 3.2 关系类型（12种核心关系）

| 关系 | 示例三元组 |
|------|-----------|
| 疾病-典型症状 | (高血压)-[典型症状]->(头晕) |
| 疾病-推荐食物 | (高血压)-[推荐食物]->(芹菜) |
| 疾病-禁忌食物 | (高血压)-[禁忌食物]->(咸菜) |
| 疾病-推荐运动 | (高血压)-[推荐运动]->(快走) |
| 疾病-禁忌运动 | (高血压)-[禁忌运动]->(剧烈跑跳) |
| 药品-适应症 | (硝苯地平)-[适应症]->(高血压) |
| 药品-禁忌症 | (硝苯地平)-[禁忌症]->(严重低血压) |
| 药品-食物相互作用 | (硝苯地平)-[相互作用]->(西柚) |
| 症状-关联疾病 | (头痛)-[关联疾病]->(高血压) |
| 科室-收治疾病 | (心内科)-[收治疾病]->(高血压) |
| 检查-诊断疾病 | (血压测量)-[诊断疾病]->(高血压) |

## 4. Education Agent 实现架构

### 4.1 整体流程

```
用户语音 → STT → 意图识别 (LLM) → 知识图谱查询 (Cypher) → 答案生成 (LLM) → TTS
                              ↓ (通用问答)
                           Fallback LLM
```

### 4.2 核心代码模块

**模块1：Neo4j 连接与查询服务**

```python
# knowledge_graph/kg_service.py
from neo4j import AsyncGraphDatabase

class HypertensionKGService:
    def __init__(self, uri, user, password):
        self.driver = AsyncGraphDatabase.driver(uri, auth=(user, password))
    
    async def query(self, cypher_query: str, params: dict = None):
        async with self.driver.session() as session:
            result = await session.run(cypher_query, params)
            return [record.data() for record in await result.data()]
    
    async def get_disease_info(self, disease_name: str):
        """获取疾病的基本信息及关联实体"""
        query = """
        MATCH (d:Disease {name: $name})
        OPTIONAL MATCH (d)-[r:典型症状]->(s:Symptom)
        OPTIONAL MATCH (d)-[r2:推荐食物]->(f:Food)
        OPTIONAL MATCH (d)-[r3:禁忌食物]->(f2:Food)
        OPTIONAL MATCH (d)-[r4:推荐运动]->(e:Exercise)
        RETURN d, collect(DISTINCT s.name) as symptoms,
               collect(DISTINCT f.name) as recommended_foods,
               collect(DISTINCT f2.name) as forbidden_foods,
               collect(DISTINCT e.name) as recommended_exercises
        """
        return await self.query(query, {"name": disease_name})
    
    async def query_food_interaction(self, food_name: str):
        """查询食物与药品的相互作用"""
        query = """
        MATCH (f:Food {name: $food})-[:相互作用]-(d:Drug)
        RETURN d.name as drug, f.name as food
        """
        return await self.query(query, {"food": food_name})
```

# agents/education_agent.py
from pipecat.pipeline import Pipeline
from pipecat.processors import FrameProcessor
from pipecat.services.openai import OpenAILLMService
from knowledge_graph.kg_service import HypertensionKGService
from knowledge_graph.intent_recognizer import IntentRecognizer

class EducationAgent(FrameProcessor):
    """健康教育咨询智能体"""
    
    def __init__(self, kg_service: HypertensionKGService, llm_service: OpenAILLMService):
        super().__init__()
        self.kg = kg_service
        self.llm = llm_service
        self.intent_recognizer = IntentRecognizer(llm_service)
        
        # 图谱查询 -> 答案生成的映射函数
        self.intent_handlers = {
            "FOOD_QUERY": self._handle_food_query,
            "EXERCISE_QUERY": self._handle_exercise_query,
            "SYMPTOM_QUERY": self._handle_symptom_query,
            "INTERACTION_QUERY": self._handle_interaction_query,
            "GENERAL_QUERY": self._handle_general_query,
        }
    
    async def _handle_food_query(self, entities: dict) -> str:
        """处理饮食类问题"""
        food = entities.get("food")
        if not food:
            return "请问您想了解哪种食物呢？"
        
        # 1. 查询图谱获取食物信息
        result = await self.kg.query("""
            MATCH (f:Food {name: $food})
            OPTIONAL MATCH (f)-[:推荐]->(d:Disease {name: '高血压'})
            OPTIONAL MATCH (f)-[:禁忌]->(d2:Disease {name: '高血压'})
            RETURN f, 
                   CASE WHEN d IS NOT NULL THEN '推荐' 
                        WHEN d2 IS NOT NULL THEN '禁忌' 
                        ELSE '中性' END as status
        """, {"food": food})
        
        if not result:
            return await self._fallback_llm(f"高血压患者能否吃{food}？")
        
        # 2. 将图谱结果注入LLM生成自然语言回答
        context = f"根据医学知识图谱，{food}对高血压患者属于'{result[0]['status']}'食物。"
        return await self._generate_answer(context, entities)

        """处理药物-食物相互作用查询"""
        # 查询图谱中的相互作用关系
        pass
    
    async def _generate_answer(self, context: str, entities: dict) -> str:
        """使用LLM将图谱查询结果转化为自然语言回答"""

        你是一位高血压健康教育助手。基于以下知识图谱检索结果，用温和、易懂的语言回答用户。
        
        知识库信息: {context}
        用户问题涉及: {entities}
        
        要求:
        1. 答案必须基于知识库信息，不要编造
        2. 语气友善，鼓励患者
        3. 添加医疗免责声明: "本回答仅供参考，具体请咨询医生"
