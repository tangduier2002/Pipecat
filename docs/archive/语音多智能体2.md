# 项目文档：高血压自我管理多智能体系统（基于 Pipecat + 知识图谱）

## 1. 系统全景图

```
用户语音/文本输入
       ↓
┌─────────────────────────────────────────────────────┐
│              Triage Agent (分诊/路由)               │
│  识别意图: 记录数据? 咨询知识? 情绪倾诉? 紧急情况?   │
└──────┬──────────────┬──────────────┬───────────────┘
       │              │              │
       ↓              ↓              ↓
┌─────────────┐ ┌─────────────┐ ┌─────────────────┐
│ Data Monitor │ │  Education  │ │  Motivation     │
│   Agent      │ │   Agent     │ │    Agent        │
│ (数据记录&   │ │ (知识图谱   │ │ (情感支持&      │
│  异常预警)   │ │  问答)      │ │  激励)          │
└──────┬──────┘ └──────┬──────┘ └────────┬────────┘
       │              │              │
       └──────────────┼──────────────┘
                      ↓
              ┌───────────────┐
              │ Patient       │
              │ Profile Agent │
              │ (共享状态/    │
              │  数据中枢)    │
              └───────────────┘
```

**关键设计原则**：
- **串行路由**：Triage 决定下一步交给谁，完成后可回到 Triage 或结束
- **并行扇出**：异常情况时，Monitor 可同时触发 Education（给建议）+ Motivation（给安抚）
- **共享上下文**：所有 Agent 通过 `PatientProfile` 读写用户状态

## 2. 各智能体职责与 Prompt 设计

| 智能体 | 核心职责 | System Prompt 核心指令 |
|--------|---------|----------------------|
| **Triage** | 意图识别 + 任务路由 | *“你是分诊助手。将用户话语分类为：data_record, knowledge_query, emotional_support, emergency, general_chat。输出 JSON 格式意图及提取的实体。”* |
| **Data Monitor** | 记录血压/心率；风险等级判断 | *“你是数据监测员。提取收缩压/舒张压/心率。若收缩压≥180或舒张压≥120，标记为 emergency 并触发并行广播。”* |
| **Education** | 知识图谱问答（非药物） | *“你是健康教育师。仅基于 Neo4j 知识图谱回答饮食、运动、症状疑问。禁止给出药物剂量建议。回答末尾加免责声明。”* |
| **Motivation** | 情感识别 + 鼓励 | *“你是暖心陪伴者。识别用户情绪（焦虑/沮丧/平静），给予共情回应，结合用户近期数据提供正向激励。”* |
| **Profile** | 存储/查询用户档案 | 非 LLM 智能体，纯数据服务（内存/Redis/数据库） |

## 3. 智能体间通信协议（基于 Pipecat Frame）

Pipecat 通过自定义 `Frame` 传递数据。我们定义以下帧类型：

```python
# frames.py
from dataclasses import dataclass
from pipecat.frames.frames import Frame

@dataclass
class UserIntentFrame(Frame):
    intent: str          # data_record | knowledge_query | emotional_support | emergency | general_chat
    entities: dict       # 提取的实体 {food: "香蕉", systolic: 160, ...}
    raw_text: str

@dataclass
class ProfileUpdateFrame(Frame):
    updates: dict        # 待写入 Profile 的数据

@dataclass
class BroadcastFrame(Frame):
    """并行广播帧，用于 emergency 场景"""
    message: str
    targets: list[str]   # ["education", "motivation"]
```

**路由逻辑**（在 Triage Agent 中）：
```python
async def process_frame(self, frame: Frame):

            await self.push_to_education(intent_data)
        elif intent_data.intent == "data_record":
            await self.push_to_monitor(intent_data)
```

## 6. 多智能体 Pipeline 编排（`pipeline_factory.py`）

```python
from pipecat.pipeline import Pipeline, ParallelPipeline
from pipecat.services.deepgram import DeepgramSTTService
from pipecat.services.cartesia import CartesiaTTSService
from agents.triage_agent import TriageAgent
from agents.monitor_agent import MonitorAgent
from agents.education_agent import EducationAgent
from agents.motivation_agent import MotivationAgent
from profile.patient_profile import PatientProfile

def build_pipeline():
    # 共享状态
    profile = PatientProfile()
    
    # 初始化服务
    stt = DeepgramSTTService()
    tts = CartesiaTTSService()
    llm = OpenAILLMService()  # 所有 Agent 共用或各自实例化
    
    # 创建 Agents（注入 profile 和 kg_service）
    triage = TriageAgent(llm=llm, profile=profile)
    monitor = MonitorAgent(llm=llm, profile=profile)
    education = EducationAgent(llm=llm, kg_service=KGService(), profile=profile)
    motivation = MotivationAgent(llm=llm, profile=profile)
    
    # Pipecat 主管线：串行 + 条件路由
    # 注意：Pipecat 本身是线性管道，但我们可以通过自定义 Processor 
    # 在 Triage 中动态将帧推送到不同子管道。
    # 这里采用单一 Pipeline，由 Triage 负责路由分发。
    
    pipeline = Pipeline([
        stt,               # 语音 → 文本帧
        triage,            # 路由分发（内部根据意图 push 到不同 Agent）
        # 注意：以下 Agent 不直接挂载在主线，而是由 Triage 动态调用
        # 但为了演示，可以用 ParallelPipeline 实现 emergency 并行
    ])
    
    # 注册子 Agent 到 Triage 的路由表
    triage.register_route("knowledge_query", education)
    triage.register_route("data_record", monitor)
    triage.register_route("emotional_support", motivation)
    triage.register_route("emergency", ParallelPipeline([education, motivation]))  # 并行
    
    return pipeline
```

### `agents/triage_agent.py` 核心路由方法
```python
class TriageAgent(FrameProcessor):
    def __init__(self, llm, profile):
        super().__init__()
        self.llm = llm
        self.profile = profile
        self.routes = {}
    
    def register_route(self, intent: str, agent):
        self.routes[intent] = agent
    
    async def process_frame(self, frame: Frame):
        if isinstance(frame, TranscriptionFrame):
            intent_data = await self._classify_intent(frame.text)
            target_agent = self.routes.get(intent_data["intent"])
            if target_agent:
                # 构造意图帧并推送给目标 Agent
                intent_frame = UserIntentFrame(
                    intent=intent_data["intent"],
                    entities=intent_data["entities"],
                    raw_text=frame.text
                )
                await target_agent.push_frame(intent_frame)
            else:
                # 通用回复
                await self.push_frame(TextFrame("请再说一遍，我没听清"))
```
