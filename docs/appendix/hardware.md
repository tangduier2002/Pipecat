## 形态一：「健康守护相框」（主推形态）

将智能终端伪装成家庭中已有的无侵入感物品——电子相框，降低老年人对「医疗设备」的抗拒心理。

```
┌──────────────────────────────────┐
│  ┌──────────────────────────┐    │
│  │    10.1寸 IPS 触摸屏      │    │
│  │    (显示家人照片/健康数据)  │    │
│  └──────────────────────────┘    │
│  [🔊 远场麦克风阵列]  [📷 摄像头]  │
│  [🔈 大音量扬声器]    [🔴 SOS键]  │
│  底座：智能药盒(7格/周) / 无线充电板 / 蓝牙网关 │
└──────────────────────────────────┘
```

核心优势：日常显示家人照片消除「被监护感」；主动语音唤醒无需老人操作屏幕。

## 形态二：「智能药盒基站」（轻量替代形态）

- 7 格智能药盒，独立 LED 灯和蜂鸣提醒
- 内置 4G 模块，不依赖 WiFi
- 一键呼叫 AI 健康教练（语音通话模式）
- 低功耗，充电一次使用两周
